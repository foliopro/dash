Desglose Matemático Ley 797 de 2003

La Tasa de Reemplazo (TR) se calcula como la suma de la Tasa Básica (R) más la Bonificación por Semanas Adicionales (PA):

TR = R + PA
R = 65,5 - 0,5 x ( IBL / Smin )
PA = ( Semanas Totales - 1.300 ) / 50 x 1,5%
Desarrollo Escenario 1:

S = $31.944.579 / $2.567.367 = 12,44 SMLMV
R = 65,5 - (0,5 x 12,44) = 59,28%
PA = (1.937,80 - 1.300) / 50 x 1,5 = 18,00%
TR Final = 59,28% + 18,00% = 77,28%

Desarrollo Escenario 2:

S = $36.495.089 / $2.567.367 = 14,21 SMLMV
R = 65,5 - (0,5 x 14,21) = 58,39%
PA = (1.937,80 - 1.300) / 50 x 1,5 = 18,00%
TR Final = 58,39% + 18,00% = 76,39%
